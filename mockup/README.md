# ReFind 화면 시안 v2 (지도 중심)

실제 프론트엔드 구현 전에 화면 구성과 사용 흐름을 확인하기 위한 **HTML 시안**입니다. 서버 없이 브라우저에서 바로 열립니다.

## 여는 방법

`index.html`을 브라우저로 열면 사건 목록 화면으로 이동합니다. css·js 파일이 같은 폴더에 있어야 하므로 폴더째로 받아서 여세요.

## 화면 구성

| 파일 | 화면 | 시나리오 |
| --- | --- | --- |
| `01_cases.html` | 사건 목록 (진입 화면) — 사건 선택, 미확인 출현 알림, 환경 설정 상태 | 공통 |
| `02_camera.html` | 지도·카메라 배치 — 카메라 위치·방향, 도보 경로 보정, 위험지역 그리기 | S1 |
| `03_video.html` | 영상 등록 — 지도에서 카메라를 눌러 녹화 영상 등록, 분석 진행·실패·재시도 | S1 |
| `04_case_new.html` | 사건 등록 — 보호자 신고 내용(시각·장소·정확도) + 실종자 사진(기본) 또는 영상에서 직접 선택 | S2 시작 |
| `05_workspace.html` | **사건 수색** — 후보 확인 · 동선 · 수색·감시를 지도 한 화면에서 처리, 사건 종결 | S2 · S3 |
| `08_flow.html` | 전체 화면 흐름도 (단계별 구조 기준, 검증 예정) | — |
| `00_시안목록.html` | 시안 목록, 시연 데이터 초기화 | — |

### 사건 수색 화면의 핵심

- 지도는 항상 떠 있고, 상단에서 **후보 확인 / 동선 / 수색·감시** 모드를 전환합니다.
- 카메라·후보·확정 장면을 누르면 **지도 위, 그 카메라 옆에 영상 카드**가 뜹니다.
- 후보는 지도 마커·시간축·목록이 **같은 번호와 색**으로 연결되어, 어느 후보가 어느 카메라에서 언제 나왔는지 한 번에 보입니다.
- 확정하면 그 장면을 새 기준점으로 앞뒤 구간을 다시 검색합니다. 신고 지점은 CCTV 장면이 아니라 별도 핀으로 표시합니다.

## 시안의 범위와 한계

- 로그인·역할 구분 없이 사용자 1명이 모든 기능을 사용하는 것으로 설계했습니다.
- 지도는 카카오맵이 아닌 시안용 캠퍼스 도식이고, 인물은 옷 색만 있는 비식별 실루엣입니다.
- Re-ID·서버 없이 미리 정해 둔 후보 데이터로 흐름만 재현합니다. 진행 상황은 브라우저 `localStorage`에 저장됩니다.
- 범위 계산과 예상 이동 시간에 쓴 보행 속도는 시안용 가정값입니다. 실제 값은 시험 후 정합니다.
