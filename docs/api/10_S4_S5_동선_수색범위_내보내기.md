## 이 문서에서 다루는 것

- 판정 결과를 지도에 보여 주기 위한 조회 API 3개
- 동선(`route`): 확정 판정만 시간순으로 이은 점과 구간. 구간 경로는 도보 그래프 기반 추정이다
- 수색 범위(`search-area`): 기준점, 경과 시간, 보행 속도로 계산한 높음·중간·낮음 범위, 위험 지역 경고, 우선 수색 지역
- 내보내기(`export`): 판정 기록을 csv로 내려받는 확장 기능

## 10. S4 동선, S5 수색 범위, 내보내기

### 10.1 `GET /api/cases/{case_id}/route` 동선

```json
200 OK
{
  "case_id": 5,
  "points": [
    {
      "order": 1,
      "decision_id": 40,
      "camera": { "id": 4, "name": "도서관 출입구" },
      "location": { "lat": 37.5670, "lng": 126.9790 },
      "at": "2026-11-08T13:12:40+09:00",
      "video_id": 13,
      "video_offset_sec": 760.0,
      "thumbnail_url": "/api/tracklets/412/thumbnail"
    }
  ],
  "segments": [
    {
      "from_order": 0,
      "to_order": 1,
      "path": [ { "lat": 37.5665, "lng": 126.9780 }, { "lat": 37.5670, "lng": 126.9790 } ],
      "estimated": true
    }
  ],
  "updated_at": "2026-11-08T14:10:05+09:00"
}
```

- `points`: 취소되지 않은 확정 판정만 시간순으로 넣는다. `order` 0은 사건의 마지막 목격 지점.
- `segments.estimated`: 항상 `true`. 도보 그래프 기반 추정 경로이며 실제 통과 궤적이 아니다.
- 에러: `404 not_found`

### 10.2 `GET /api/cases/{case_id}/search-area` 수색 범위

```json
200 OK
{
  "case_id": 5,
  "status": "ready",
  "base": {
    "decision_id": 40,
    "location": { "lat": 37.5670, "lng": 126.9790 },
    "at": "2026-11-08T13:12:40+09:00"
  },
  "calculated_at": "2026-11-08T14:10:05+09:00",
  "elapsed_min": 57,
  "speed_mps": 0.8,
  "ranges": [
    { "level": "high", "polygon": [ ... ] },
    { "level": "medium", "polygon": [ ... ] },
    { "level": "low", "polygon": [ ... ] }
  ],
  "warnings": [
    { "zone_id": 2, "zone_name": "정문 앞 간선도로", "range_level": "medium" }
  ],
  "priority_areas": [
    { "rank": 1, "camera_ids": [6, 7], "reason": "이탈 방향, 위험 지역 근접" }
  ]
}
```

| `status` | 의미 |
|---|---|
| `ready` | 계산 결과 있음 |
| `calculating` | 재계산 중. 나머지 필드는 이전 결과 |
| `not_available` | 계산할 수 없음 (기준점 카메라가 도보 그래프에 연결되지 않음 등) |

- `level`의 높음·중간·낮음은 산정 기준에 따른 구분이며 존재 확률이 아니다.
- 에러: `404 not_found`

### 10.3 `GET /api/cases/{case_id}/export` 기록 내보내기 (확장 기능)

- 쿼리: `format=csv` (현재 csv만)
- 응답: `200`, `Content-Type: text/csv`, `Content-Disposition: attachment; filename="case_5.csv"`
- 열: 판정 ID, 판정 종류, 카메라, 등장 시각, 영상 ID, 영상 위치, 유사도, 메모, 판정 시각, 취소 시각
- 에러: `404 not_found`, `422 validation_error` (지원하지 않는 형식)
