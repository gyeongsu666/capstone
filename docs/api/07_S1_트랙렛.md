## 이 문서에서 다루는 것

- 트랙렛: 영상 분석 결과로 나온, 한 영상 안에서 추적된 한 사람의 등장 구간
- 영상별 트랙렛 목록, 트랙렛 상세, 대표 이미지(썸네일) API 3개
- `track_no`는 영상 안에서만 의미가 있다. 다른 영상의 같은 번호는 같은 사람이 아니다
- 트랙렛은 사건 등록(08)과 검색 후보(09)에서 다시 쓰인다

---

## 7. S1 영상 준비: 트랙렛

### 트랙렛 객체

```json
{
  "id": 301,
  "video_id": 12,
  "camera_id": 3,
  "track_no": 297,
  "start_at": "2026-11-08T13:02:05+09:00",
  "end_at": "2026-11-08T13:02:18+09:00",
  "start_offset_sec": 125.0,
  "end_offset_sec": 138.0,
  "entry_direction_deg": 270,
  "exit_direction_deg": 90,
  "thumbnail_url": "/api/tracklets/301/thumbnail"
}
```

- `track_no`는 영상 안에서만 쓰는 추적 번호다. 다른 영상의 같은 번호는 같은 사람이 아니다.

### 7.1 `GET /api/videos/{video_id}/tracklets` 영상 속 인물 목록

- 쿼리: `start_offset_sec`, `end_offset_sec` (해당 구간에 등장한 트랙렛만), `page`, `per_page`
- 응답: `200`, 트랙렛 객체 목록
- 에러: `404 not_found`, `409 not_ready` (분석 전)

### 7.2 `GET /api/tracklets/{tracklet_id}` 트랙렛 상세

- 응답: `200`, 트랙렛 객체
- 에러: `404 not_found`

### 7.3 `GET /api/tracklets/{tracklet_id}/thumbnail` 대표 이미지

- 응답: `200`, `Content-Type: image/jpeg`
- 에러: `404 not_found`
