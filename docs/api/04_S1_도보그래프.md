## 이 문서에서 다루는 것

- 사람이 걸어 다닐 수 있는 길을 노드(지점)와 간선(길)으로 표현하는 API 7개
- 노드는 카메라와 연결할 수 있고, 간선은 두 노드 사이 거리와 경로 좌표를 가진다
- `GET /api/walk-graph`는 전체 그래프와 함께 그래프에 연결되지 않은 카메라 목록을 준다
- 노드를 지우면 연결된 간선도 함께 지워진다
- 이 그래프는 후보의 이동 시간 검사(09), 동선·수색 범위 계산(10)에 쓰인다

## 4. S1 사전 준비: 도보 그래프

### 노드 객체

```json
{
  "id": 7,
  "name": "본관 앞 교차점",
  "location": { "lat": 37.5666, "lng": 126.9781 },
  "camera_id": 3
}
```

### 간선 객체

```json
{
  "id": 15,
  "from_node_id": 7,
  "to_node_id": 8,
  "distance_m": 42.5,
  "path": [
    { "lat": 37.5666, "lng": 126.9781 },
    { "lat": 37.5668, "lng": 126.9785 }
  ],
  "bidirectional": true
}
```

| 필드 | 필수 | 규칙 |
|---|---|---|
| `from_node_id`, `to_node_id` | O | 존재하는 노드, 서로 달라야 함 |
| `distance_m` | X | 생략하면 `path`로 계산 |
| `path` | X | 생략하면 두 노드를 직선으로 연결 |
| `bidirectional` | X | 기본 `true` |

### 4.1 `GET /api/walk-graph` 도보 그래프 전체

```json
200 OK
{
  "nodes": [ { 노드 객체 }, ... ],
  "edges": [ { 간선 객체 }, ... ],
  "unconnected_camera_ids": [5]
}
```

- `unconnected_camera_ids`: 그래프에 연결되지 않아 경로 계산에서 빠지는 카메라

### 4.2 `POST /api/walk-graph/nodes` 노드 추가

- 요청: `{"name", "location", "camera_id"(선택)}`
- 응답: `201`, 노드 객체
- 에러: `422 validation_error`, `404 not_found` (`camera_id`가 없음)

### 4.3 `PATCH /api/walk-graph/nodes/{node_id}` 노드 수정

- 응답: `200`, 노드 객체
- 에러: `404 not_found`, `422 validation_error`

### 4.4 `DELETE /api/walk-graph/nodes/{node_id}` 노드 삭제

- 연결된 간선도 함께 삭제한다.
- 응답: `204`
- 에러: `404 not_found`

### 4.5 `POST /api/walk-graph/edges` 간선 추가

- 요청: 간선 객체에서 `id`를 뺀 값
- 응답: `201`, 간선 객체
- 에러: `404 not_found` (노드 없음), `409 invalid_state` (같은 두 노드 사이 간선이 이미 있음), `422 validation_error`

### 4.6 `PATCH /api/walk-graph/edges/{edge_id}` 간선 보정

- 응답: `200`, 간선 객체
- 에러: `404 not_found`, `422 validation_error`

### 4.7 `DELETE /api/walk-graph/edges/{edge_id}` 간선 삭제

- 응답: `204`
- 에러: `404 not_found`
