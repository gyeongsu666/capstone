## 이 문서에서 다루는 것

- S1 사전 준비 단계에서 CCTV 카메라를 등록·조회·보정·삭제하는 API 5개
- 카메라는 위치, 방향(`direction_deg`), 화각(`fov_deg`)을 가진다
- `walk_node_id`로 도보 그래프 노드와 연결되어야 경로 계산에 쓰인다(04 참고)
- 연결된 영상이 있으면 삭제할 수 없다(`409 resource_in_use`)

---

## 3. S1 사전 준비: 카메라

### 카메라 객체

```json
{
  "id": 3,
  "name": "본관 1층 출입구",
  "location": { "lat": 37.5665, "lng": 126.9780 },
  "direction_deg": 90,
  "fov_deg": 70,
  "view_distance_m": 25,
  "walk_node_id": 7,
  "video_count": 2,
  "created_at": "2026-11-08T10:00:00+09:00",
  "updated_at": "2026-11-08T10:00:00+09:00"
}
```

| 필드 | 필수 | 규칙 |
|---|---|---|
| `name` | O | 1~100자 |
| `location` | O | 위도 -90~90, 경도 -180~180 |
| `direction_deg` | O | 0 이상 360 미만 |
| `fov_deg` | O | 1~180 |
| `view_distance_m` | X | 0보다 큼. 화각 부채꼴 표시용 |
| `walk_node_id` | X | 연결된 도보 그래프 노드. 경로 계산에 필요 |

### 3.1 `GET /api/cameras` 카메라 목록

- 쿼리: `page`, `per_page`
- 응답: `200`, 카메라 객체 목록

### 3.2 `POST /api/cameras` 카메라 등록

```json
요청
{
  "name": "본관 1층 출입구",
  "location": { "lat": 37.5665, "lng": 126.9780 },
  "direction_deg": 90,
  "fov_deg": 70,
  "view_distance_m": 25
}
```

- 응답: `201`, 카메라 객체, `Location: /api/cameras/3`
- 에러: `422 validation_error`

### 3.3 `GET /api/cameras/{camera_id}` 카메라 상세

- 응답: `200`, 카메라 객체
- 에러: `404 not_found`

### 3.4 `PATCH /api/cameras/{camera_id}` 카메라 보정

- 요청: 바꿀 필드만 보낸다. 예: `{"direction_deg": 95, "fov_deg": 65}`
- 응답: `200`, 수정된 카메라 객체
- 에러: `404 not_found`, `422 validation_error`

### 3.5 `DELETE /api/cameras/{camera_id}` 카메라 삭제

- 응답: `204`
- 에러: `404 not_found`, `409 resource_in_use` (연결된 영상이 있음. 영상을 먼저 삭제)
