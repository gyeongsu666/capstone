## 이 문서에서 다루는 것

- 실종 사건을 등록하고 관리하는 API 5개
- 등록할 때 실종자 사진(`photo`)과 영상 속 인물(`tracklet_id`) 중 하나만 보낸다
- 등록하면 `202`를 받고 특징 추출이 끝나면 상태가 `processing` → `ready`가 된다. `ready`여야 검색할 수 있다
- 마지막 목격 위치·시각과 대상 유형(보행 속도 기준)이 필수다
- 종결은 PATCH로 `status: closed`와 사유를 보낸다

## 8. S2 사건

### 사건 객체

```json
{
  "id": 5,
  "status": "ready",
  "target_type": "dementia_elderly",
  "query_source": "photo",
  "query_tracklet_id": null,
  "last_seen": {
    "location": { "lat": 37.5665, "lng": 126.9780 },
    "at": "2026-11-08T13:00:00+09:00"
  },
  "photo_url": "/api/cases/5/photo",
  "model_version": "reid-v1",
  "task_id": "a1b2c3d4-0000-4000-8000-000000000005",
  "error": null,
  "memo": "회색 점퍼, 검은 바지",
  "closed_reason": null,
  "found_at": null,
  "created_at": "2026-11-08T14:00:00+09:00"
}
```

| `status` | 의미 |
|---|---|
| `processing` | 질의 특징 추출 중 |
| `ready` | 검색 가능 |
| `failed` | 특징 추출 실패. `error`에 사유 |
| `closed` | 종결 |

### 8.1 `POST /api/cases` 사건 등록

- 요청: `multipart/form-data`. 사진(`photo`)과 `tracklet_id` 중 하나만 보낸다.

| 필드 | 필수 | 설명 |
|---|---|---|
| `photo` | 둘 중 하나 | 실종자 전신 사진 |
| `tracklet_id` | 둘 중 하나 | 분석된 영상 속 인물로 대상 지정 |
| `bbox` | X | 사진 속 대상 영역 JSON `{"x","y","w","h"}` (픽셀). 사진에 여러 사람이 있을 때 |
| `last_seen_lat`, `last_seen_lng` | O | 마지막 목격 위치 |
| `last_seen_at` | O | 마지막 목격 시각 |
| `target_type` | O | 보행 속도의 `target_type` 중 하나 |
| `memo` | X | 인상착의 등 메모, 500자 이하 |

```json
202 Accepted
Location: /api/cases/5
{
  "case_id": 5,
  "task_id": "a1b2c3d4-0000-4000-8000-000000000005",
  "status_url": "/api/tasks/a1b2c3d4-0000-4000-8000-000000000005"
}
```

- `tracklet_id`로 등록하면 저장된 특징 벡터를 쓸 수 있어 바로 `ready`가 될 수 있다. 이때도 응답 형식은 같다.
- 에러: `400 invalid_file`, `413 file_too_large`, `404 not_found` (트랙렛 없음), `422 validation_error` (사진과 트랙렛을 둘 다 보내거나 둘 다 안 보냄)

### 8.2 `GET /api/cases` 사건 목록

- 쿼리: `status`, `page`, `per_page`
- 응답: `200`, 사건 객체 목록

### 8.3 `GET /api/cases/{case_id}` 사건 정보

- 응답: `200`, 사건 객체
- 에러: `404 not_found`

### 8.4 `PATCH /api/cases/{case_id}` 사건 수정, 종결

```json
종결 요청
{
  "status": "closed",
  "closed_reason": "found",
  "found_at": "2026-11-08T16:40:00+09:00"
}
```

- 수정 가능 필드: `memo`, `target_type`, `status`(`closed`로만 변경 가능), `closed_reason`(`found`, `cancelled`, `other`), `found_at`
- 응답: `200`, 사건 객체
- 에러: `404 not_found`, `409 invalid_state` (이미 종결됨), `422 validation_error`

### 8.5 `GET /api/cases/{case_id}/photo` 등록 사진

- 응답: `200`, `Content-Type: image/jpeg` 또는 `image/png`
- 에러: `404 not_found` (사진 없이 트랙렛으로 등록한 사건 포함)
