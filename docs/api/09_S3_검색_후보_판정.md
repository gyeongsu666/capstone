## 이 문서에서 다루는 것

- 사건 대상과 닮은 사람을 영상에서 찾고, 사람이 후보를 판정하는 흐름의 API 7개
- 검색: 기준점(마지막 목격 또는 확정 판정)에서 시간 범위·방향·유사도 기준으로 후보를 찾는다. `202` 비동기 작업
- 후보: 유사도 점수와 이동 시간 검사(`route_check`) 결과를 가진다. 유사도는 동일인 확률이 아니다
- 판정: `confirmed`(동일인 확정), `excluded`(후보 제외), `absent`(해당 구간에 없음) 3종류
- 확정 판정을 저장하거나 취소하면 동선·수색 범위 재계산이 등록된다(10 참고). 취소는 지우지 않고 `cancelled_at`만 기록한다

## 9. S3 검색, 후보, 판정

### 검색 객체

```json
{
  "id": 21,
  "case_id": 5,
  "status": "done",
  "base": {
    "location": { "lat": 37.5665, "lng": 126.9780 },
    "at": "2026-11-08T13:00:00+09:00",
    "decision_id": null
  },
  "direction": "forward",
  "time_window_min": 30,
  "similarity_threshold": 0.5,
  "top_k": 20,
  "candidate_count": 7,
  "held": false,
  "excluded_video_count": 1,
  "task_id": "b2c3d4e5-0000-4000-8000-000000000021",
  "created_at": "2026-11-08T14:05:00+09:00"
}
```

| 필드 | 설명 |
|---|---|
| `status` | `running`, `done`, `failed` |
| `base` | 검색 기준점. `decision_id`가 있으면 그 확정 판정이 기준점 |
| `direction` | `forward`(이후), `backward`(이전), `both` |
| `held` | 기준을 통과한 후보가 없어 "신뢰할 후보 없음"으로 보류했는지 |
| `excluded_video_count` | 분석이 끝나지 않아 검색에서 빠진 영상 수. 화면 안내용 |

### 9.1 `POST /api/cases/{case_id}/searches` 검색 시작

```json
요청
{
  "base_decision_id": null,
  "direction": "forward",
  "time_window_min": 30,
  "similarity_threshold": null,
  "top_k": 20
}
```

| 필드 | 필수 | 규칙 |
|---|---|---|
| `base_decision_id` | X | 생략하면 사건의 마지막 목격 정보가 기준점 |
| `direction` | X | 기본 `forward` |
| `time_window_min` | X | 기본 30, 1~720 |
| `similarity_threshold` | X | 생략하면 모델별 서버 기본값 |
| `top_k` | X | 기본 20, 1~100 |

- 응답: `202`, `{"search_id", "task_id", "status_url"}`, `Location: /api/cases/5/searches/21`
- 에러: `404 not_found`, `409 not_ready` (사건이 `ready`가 아님), `409 invalid_state` (종결된 사건), `422 validation_error`

### 9.2 `GET /api/cases/{case_id}/searches` 검색 이력

- 응답: `200`, 검색 객체 목록 (최신순)

### 9.3 `GET /api/cases/{case_id}/searches/{search_id}` 검색 상세

- 응답: `200`, 검색 객체
- 에러: `404 not_found`

### 후보 객체

```json
{
  "id": 88,
  "search_id": 21,
  "rank": 1,
  "tracklet": { 트랙렛 객체 },
  "camera": { "id": 4, "name": "도서관 출입구" },
  "appeared_at": "2026-11-08T13:12:40+09:00",
  "video_id": 13,
  "video_offset_sec": 760.0,
  "similarity": 0.62,
  "route_check": {
    "status": "warning",
    "required_time_sec": 540,
    "elapsed_time_sec": 400,
    "message": "도보 예상 시간보다 빠르게 도착했습니다."
  },
  "decision": null
}
```

- `similarity`는 외형 유사도 점수다. 동일인일 확률이 아니다.
- `route_check.status`: `ok`, `warning`. 경고 후보는 제외하지 않고 순위만 낮춘다.
- `decision`: 이 후보에 대한 판정이 있으면 `{"id", "type"}`

### 9.4 `GET /api/cases/{case_id}/candidates` 후보 목록

- 쿼리: `search_id`(생략하면 최신 검색), `include_decided`(기본 `true`), `page`, `per_page`
- 응답: `200`, 후보 객체 목록 (`rank` 순)
- 에러: `404 not_found`, `409 not_ready` (검색이 끝나지 않음)

### 판정 객체

```json
{
  "id": 40,
  "case_id": 5,
  "type": "confirmed",
  "candidate_id": 88,
  "tracklet_id": 412,
  "absence": null,
  "memo": "가방 일치",
  "cancelled_at": null,
  "recalculation_task_id": "c3d4e5f6-0000-4000-8000-000000000040",
  "created_at": "2026-11-08T14:10:00+09:00"
}
```

| `type` | 의미 | 필수 값 |
|---|---|---|
| `confirmed` | 동일인 확정. 다음 검색의 기준점이 됨 | `candidate_id` |
| `excluded` | 이 후보만 제외 | `candidate_id` |
| `absent` | 확인한 카메라·시간 구간에 대상 없음 | `absence` |

```json
absent 판정 요청
{
  "type": "absent",
  "absence": {
    "camera_id": 4,
    "start_at": "2026-11-08T13:05:00+09:00",
    "end_at": "2026-11-08T13:25:00+09:00"
  },
  "memo": "해당 구간 전체 확인"
}
```

### 9.5 `POST /api/cases/{case_id}/decisions` 판정 저장

- 응답: `201`, 판정 객체, `Location: /api/cases/5/decisions/40`
- `confirmed`이면 동선·수색 범위 재계산 작업을 등록하고 `recalculation_task_id`를 채운다. 그 외에는 `null`.
- 에러: `404 not_found`, `409 invalid_state` (이미 판정한 후보, 종결된 사건), `422 validation_error` (`type`과 필수 값이 맞지 않음, `start_at` > `end_at`)

### 9.6 `GET /api/cases/{case_id}/decisions` 판정 이력

- 쿼리: `type`, `include_cancelled`(기본 `false`), `page`, `per_page`
- 응답: `200`, 판정 객체 목록 (시간순)

### 9.7 `DELETE /api/cases/{case_id}/decisions/{decision_id}` 판정 취소

- 취소한 판정은 지우지 않고 `cancelled_at`을 기록한다(검색·확인 이력 보존).
- `confirmed` 판정을 취소하면 재계산 작업을 등록한다.
- 응답: `204`
- 에러: `404 not_found`, `409 invalid_state` (이미 취소됨, 종결된 사건)
