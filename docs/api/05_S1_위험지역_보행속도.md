## 이 문서에서 다루는 것

- 위험 지역(공사장, 도로, 하천 등) 폴리곤을 관리하는 API 4개
- 대상 유형별 보행 속도(아동, 치매 노인, 성인)를 조회·설정하는 API 2개
- 위험 지역은 수색 범위 결과의 `warnings`에, 보행 속도는 수색 범위 계산에 쓰인다(10 참고)
- 보행 속도 `target_type`은 사건 등록 시 대상 유형으로도 쓰인다(08 참고)

## 5. S1 사전 준비: 위험 지역, 보행 속도

### 위험 지역 객체

```json
{
  "id": 2,
  "name": "정문 앞 간선도로",
  "zone_type": "road",
  "polygon": [
    { "lat": 37.5660, "lng": 126.9770 },
    { "lat": 37.5662, "lng": 126.9775 },
    { "lat": 37.5658, "lng": 126.9776 }
  ],
  "created_at": "2026-11-08T10:20:00+09:00"
}
```

| 필드 | 필수 | 규칙 |
|---|---|---|
| `name` | O | 1~100자 |
| `zone_type` | O | `construction`, `road`, `river`, `other` |
| `polygon` | O | 꼭짓점 3개 이상, 자기 교차 없음 |

### 5.1 `GET /api/danger-zones` 위험 지역 목록

- 응답: `200`, 위험 지역 객체 목록

### 5.2 `POST /api/danger-zones` 위험 지역 등록

- 응답: `201`, 위험 지역 객체
- 에러: `422 validation_error` (꼭짓점 부족, 자기 교차)

### 5.3 `PATCH /api/danger-zones/{zone_id}` 위험 지역 수정

- 응답: `200`, 위험 지역 객체
- 에러: `404 not_found`, `422 validation_error`

### 5.4 `DELETE /api/danger-zones/{zone_id}` 위험 지역 삭제

- 응답: `204`
- 에러: `404 not_found`

### 보행 속도 객체

```json
{
  "target_type": "dementia_elderly",
  "label": "치매 노인",
  "speed_mps": 0.8,
  "updated_at": "2026-11-08T10:30:00+09:00"
}
```

- `target_type`: `child`, `dementia_elderly`, `adult` (초기 데이터로 3개를 넣어 둔다)

### 5.5 `GET /api/walking-speeds` 보행 속도 조회

```json
200 OK
{ "items": [ { 보행 속도 객체 }, ... ] }
```

- 항목이 적어 페이지를 나누지 않는다.

### 5.6 `PUT /api/walking-speeds/{target_type}` 보행 속도 설정

- 요청: `{"label": "치매 노인", "speed_mps": 0.8}`
- 응답: `200`, 보행 속도 객체
- 에러: `422 validation_error` (`speed_mps`는 0보다 크고 3 이하)
