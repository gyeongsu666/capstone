# 시스템 기능 요구사항 (관리자 / 사용자)

> 원본: claude.ai 문서 "시스템 기능 요구사항 (관리자 / 사용자)"의 "기능 요구사항" 탭. 2026-11-16 기준.

CCTV 기반 실종자 동선 추적 시스템의 기능을 공통 2개, 관리자 9개, 사용자 12개로 나눴다. 번호는 공통 SYS00, 관리자 SYS01, 사용자 SYS02.

| 역할 | 하는 일 | 관련 시나리오 |
| --- | --- | --- |
| 관리자 | 카메라, 지도, 영상, 계정 등 시스템 환경을 구성하고 운영. 사용자 기능도 모두 사용 가능 | S1 사전준비, S2·S3 가능 |
| 사용자(수색 담당자) | 사건을 등록하고 실종자 동선을 추적하고 수색 | S2 과거 동선 추적, S3 현재 위치 수색 |

## 공통 기능 (SYS00)

모든 기능은 로그인한 계정의 역할로 권한을 나눈다. 관리자는 사용자 기능을 모두 포함하고, 그 위에 관리자 기능을 더 가진다. **로그인은 1차 개발에 포함한다** (기술스택 최종안의 "로그인 1차 제외"는 변경됨).

| 번호 | 기능 | 요구사항 | 세부내역 |
| --- | --- | --- | --- |
| SYS00-001 | 로그인 | 등록된 계정으로만 시스템을 사용한다 | 아이디·비밀번호 로그인, 로그아웃 · 비밀번호는 해시로 저장 · 일정 시간 미사용 시 자동 로그아웃 · 회원가입 없이 관리자가 계정 발급(SYS01-007) |
| SYS00-002 | 역할별 접근 제어 | 계정의 역할에 따라 쓸 수 있는 기능과 데이터를 제한한다 | 역할은 관리자·사용자 2가지 · 관리자는 SYS01 + SYS02 전체, 사용자는 SYS02만 · 사용자는 맡은 사건만 열람, 관리자는 전체 사건 열람 · 화면 메뉴뿐 아니라 서버에서도 요청마다 역할 확인 · 모든 요청은 계정 기준으로 이용 기록에 남김(SYS01-008) |

## 관리자 기능 (SYS01)

관리자는 수색이 가능하도록 카메라·경로·영상을 미리 준비하고 시스템을 운영한다. 녹화 영상은 고정 CCTV만 관리자가 등록하고, 보행 속도는 관리자가 프리셋(성인, 어린이, 노인)만 정해 두면 사용자가 사건마다 고른다.

| 번호 | 기능 | 요구사항 | 세부내역 | 비고 |
| --- | --- | --- | --- | --- |
| SYS01-001 | 카메라 관리 | 지도 위에 CCTV 카메라를 등록하고 관리한다 | 카카오맵 위에서 위치와 촬영 방향 지정 · 이름, 설치 장소, 화각 등록·수정·삭제 · 등록된 카메라 목록과 지도 표시 | |
| SYS01-002 | 도보 경로 계산·보정 | 카메라 사이 도보 거리와 이동 시간을 계산하고 보정한다 | 카메라 쌍마다 카카오 도보 경로 API 요청 · 우회가 심한 구간(지도에 없는 샛길 가능성) 표시 · 해당 구간 거리·시간 직접 수정 | |
| SYS01-003 | 위험 지역 관리 | 수색 시 경고할 위험 지역을 등록한다 | 지도 위에 영역(다각형/원)으로 표시 · 대상 유형별 구분(실종자: 하천·공사장 / 범죄자: 인파 밀집 지역) · 등록·수정·삭제 | |
| SYS01-004 | 녹화 영상 등록 | 카메라별 녹화 영상을 시스템에 등록한다 | 카메라 선택 후 영상 업로드 · 녹화 시작 시각 입력 · 파일 저장소에 저장 | 고정 CCTV 영상만. 사건용 영상은 SYS02-009 |
| SYS01-005 | 영상 분석 관리 | 등록된 영상의 사전 분석 작업을 관리한다 | 사람 검출·추적 → 트랙렛 생성 → Re-ID 특징 추출 실행 · 진행 상태(대기/진행/완료/실패) 확인 · 실패 작업 재처리 | |
| SYS01-006 | 시스템 설정 | 검색과 추정에 쓰이는 기준값을 설정한다 | 보행 속도 프리셋(성인, 어린이, 노인) · 유사도 기준 기본값(사건마다 조정 가능), 확인 요청 기준(정확도 하한) · 현재 위치 범위 3단계 구분 기준 · 필터 여유 시간, 범위 밖 확인 요청 기준 | 보행 속도는 사용자가 사건마다 선택(SYS02-001), 유사도 기준은 사건마다 조정(SYS02-003) |
| SYS01-007 | 계정·권한 관리 | 사용자 계정과 권한을 관리한다 | 계정 생성(아이디·이름·역할 지정, 임시 비밀번호 발급, 첫 로그인 시 비밀번호 변경) · 역할(관리자/사용자) 변경 · 계정은 삭제하지 않고 비활성화(이용·확인 기록 보존) · 비밀번호 초기화 · 마지막 관리자는 자기 역할 변경·비활성화 불가 · 첫 관리자 계정은 서버 최초 실행 시 스크립트로 생성 · 계정·역할 변경 내역은 이용 기록에 남김(SYS01-008) | 신규 추가 |
| SYS01-008 | 이용 기록 조회 | 시스템 이용 기록을 조회한다 | 누가, 언제, 어떤 사건에서 검색·확인·영상 열람을 했는지 기록 · 기간·사용자·사건별 조회 | 신규 추가 (CCTV는 개인정보) |
| SYS01-009 | 데이터 보관 관리 | 사건 데이터의 보관 기간을 정하고 기간이 지나면 삭제한다 | 종료된 사건의 썸네일·특징 벡터·확인 기록 보관 기간 설정 · 녹화 영상 원본 보관 기간 설정 · 기간 만료 시 자동 삭제 · 삭제 내역 기록 | 신규 추가 (CCTV는 개인정보) |

**팀 논의 필요: 기준값 숫자** (MSW에서는 임시값 사용)

| 기준값 | 쓰이는 곳 | 정할 내용 |
| --- | --- | --- |
| 보행 속도 프리셋 | SYS01-006, SYS02-001, SYS02-006 | 성인·어린이·노인 각각의 최대 보행 속도(m/s) |
| 필터 여유 시간 | SYS02-003 | 도보 이동 시간에 더할 여유(분 또는 %) |
| 확인 요청 기준 | SYS02-004 | 유사도가 몇 점 이하일 때 담당자에게 물을지 |
| 범위 밖 확인 기준 | SYS02-003 | 범위 밖 후보를 유사도 몇 점 이상일 때 올릴지 |
| 현재 위치 3단계 기준 | SYS02-006 | 높음·중간·낮음을 나누는 거리 또는 확률 |

## 사용자 기능 (SYS02)

사용자(수색 담당자)는 사건을 등록한 뒤 후보 검색과 예/아니오 확인을 반복해 동선을 확정하고, 현재 위치를 수색한다. 애매한 장면의 확인은 관리자가 아닌 수색 담당자가 한다. 사설 CCTV처럼 사건마다 따로 받은 영상은 사용자가 직접 등록한다.

| 번호 | 기능 | 요구사항 | 세부내역 | 비고 |
| --- | --- | --- | --- | --- |
| SYS02-001 | 사건 등록 | 수색할 사건을 등록한다 | 실종자 기본 정보(이름, 나이, 인상착의) · 실종 시각과 마지막 확인 장소 · 보행 속도 프리셋 선택 | |
| SYS02-002 | 대상 지정 | 추적할 인물을 지정한다 | 실종자 사진 업로드 · 또는 영상 속 인물(트랙렛 썸네일) 직접 선택 | |
| SYS02-003 | 후보 검색 | 대상과 비슷한 인물 후보를 검색한다 | 시공간 제약 필터(도보로 갈 수 있는 카메라·시간대의 트랙렛만 추림) · 벡터 유사도 비교 · 경로 일관성 검사(이동 시간·방향이 맞지 않으면 순위 하향) · 후보 목록(썸네일, 카메라, 시각, 유사도) 표시 · 필터에 여유 시간을 두어 지도에 없는 길로 빨리 이동한 경우도 포함 · 범위 밖이라도 유사도가 매우 높으면 확인 요청으로 올림 · 유사도 기준은 관리자 기본값에서 시작해 사건마다 조정 | 지도에 직접 그리는 검색 범위 선택은 넣지 않음 |
| SYS02-004 | 확인 응답·재검색 | 애매한 장면을 담당자가 확인하고 그 결과로 다시 검색한다 | 확인이 필요한 장면(정확도 낮음, 사람 겹침, 필터 밖 출현) 제시 · 예/아니오/보류 응답(보류는 대기열 뒤로 보냄) · 확정 장면을 기준점으로 앞뒤 구간 재검색 · 모든 판단은 확인 기록으로 저장 | 장면 확인은 수색 담당자가 수행 |
| SYS02-005 | 동선 조회 | 확정된 동선을 타임라인과 지도로 보여준다 | 확정 장면을 시간 순으로 잇는 타임라인 · 지도 위 이동 경로 · 장면 클릭 시 영상 구간 재생 | |
| SYS02-006 | 현재 위치 범위 조회 | 마지막 목격 지점에서 현재 있을 수 있는 범위를 보여준다 | 경과 시간 × 보행 속도로 길 위 이동 범위 계산 · 이탈 방향 가중치 · 3단계(높음/중간/낮음) 표시 · 위험 지역 겹침 경고, 수색 우선 구역 제시 | |
| SYS02-007 | 실시간 감시 등록 | 확정된 실종자 특징으로 실시간 감시를 시작한다 | 확정 특징 벡터를 감시 대상으로 등록 · 감시 시작·중지 · 시연은 녹화 영상을 실시간처럼 재생 | |
| SYS02-008 | 출현 알림 확인 | 실종자로 보이는 인물이 나타나면 알리고 확인받는다 | 새 인물과 감시 대상 특징 매칭 후 알림(웹 화면 표시 + 알림음 + 브라우저 알림) · 예/아니오 확인 · 확인되면 동선과 수색 범위 갱신 | 알림 전달은 폴링 |
| SYS02-009 | 사건 영상 추가 | 사건마다 따로 확보한 영상(사설 CCTV, 블랙박스 등)을 등록한다 | 지도 위 촬영 위치·방향, 녹화 시작 시각 입력 · 고정 CCTV와 같은 방식으로 분석 · 기존 카메라와의 도보 경로 자동 계산 · 해당 사건에서만 사용 | 사용자도 가능(맡은 사건만) |
| SYS02-010 | 확정 취소(판단 번복) | 잘못 확정한 장면을 취소하고 이후 동선을 다시 계산한다 | 타임라인에서 확정 장면을 골라 취소 · 그 장면 이후의 확정 장면은 '재확인 필요'로 표시 · 직전 확정 장면을 기준점으로 재검색 · 취소 내역도 확인 기록에 저장 · '아니오' 판단도 번복 가능(후보를 대기열로 되돌림) · 판단 직후 8초간 되돌리기 알림, 이후에는 결정 기록에서 번복 | |
| SYS02-011 | 사건 종료 | 수색이 끝난 사건을 종료한다 | 종료 사유(발견, 수색 중단 등) 입력 · 실시간 감시 자동 해제 · 종료 후 읽기 전용으로 전환 · 보관 기간이 지나면 데이터 삭제(SYS01-009) | |
| SYS02-012 | 공동 담당 | 한 사건을 여러 담당자가 함께 수색한다 | 사건 등록자가 다른 담당자를 사건에 추가 · 확인 요청과 알림은 담당자 전원에게 표시 · 먼저 응답한 결과를 적용하고 응답자 이름을 함께 표시 · 결과에 이견이 있으면 확정 취소(SYS02-010)로 되돌림 | |

## 화면 구성

관리자는 관리자 화면 3개와 사용자 화면 3개를 모두 쓰고, 사용자는 사용자 화면 3개만 쓴다. 관리자로 로그인하면 메뉴에 두 영역이 함께 보인다. 화면별 배치는 `docs/design.md` 참고.

| 사용 가능 역할 | 화면 | 관련 기능 |
| --- | --- | --- |
| 관리자 | 카메라·지도 설정 | SYS01-001 ~ 003 |
| 관리자 | 영상 등록·분석 현황 | SYS01-004, 005 |
| 관리자 | 설정 / 계정 / 이용 기록 | SYS01-006 ~ 009 |
| 사용자, 관리자 | 사건 목록·등록 | SYS02-001, 002, 009, 011, 012 |
| 사용자, 관리자 | 동선 추적 (검색 + 확인 + 경로) | SYS02-002 ~ 005, 010 |
| 사용자, 관리자 | 현재 위치 수색·실시간 감시 | SYS02-006 ~ 008 |
| 공통 (로그인 전) | 로그인 | SYS00-001, 002 |
