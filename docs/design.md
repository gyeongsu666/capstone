# 프론트 디자인 결정

> 원본: claude.ai 문서의 "프론트 디자인" 탭. 2026-11-16 기준.
> 시안 이미지: `docs/mockups/admin-camera-map.png`, `docs/mockups/user-route-tracking.png`. 레이아웃 참고용이며, 색과 일부 배치는 이 문서가 우선한다(맨 아래 "시안에서 바뀌는 점").

레이아웃은 시안을 따르고, 강조색은 역할과 관계없이 파랑 하나만 쓴다. 후보 검색·장면 확인·경로 확인은 동선 추적 한 화면에서 처리한다.

## 전체 레이아웃

- **사이드바**: 어두운 남색, 왼쪽 고정(약 220px). 맨 위에 시스템 이름 + 역할 배지. 관리자는 "환경 설정 / 운영 / 수색" 세 묶음, 사용자는 수색 메뉴만.
- **사건 카드**: 사건에 들어가면 사이드바에 사건 번호, 실종자, 실종 시각, 보행 속도, 경과 시간. 관리자도 같음.
- **헤더**: 화면 제목 + 한 줄 요약, 그 화면의 주요 버튼은 오른쪽.
- **본문 두 가지 틀**
  - 지도형: 가운데 지도 + 오른쪽 작업 패널(약 360px). 카메라·지도 설정, 동선 추적, 현재 위치 수색.
  - 표형: 표·폼을 전체 폭으로. 사건 목록, 설정/계정/이용 기록.
  - 지도+표: 영상 등록·분석은 왼쪽 카메라 지도(위치별 영상 상태) + 오른쪽 표 (2026-11-16 사용자 요청으로 바꿈).

## 색

강조색은 파랑 하나(Ant Design 기본 primary). 버튼, 선택된 메뉴, 링크, 지금 확인 중인 후보에 쓴다. 역할은 사이드바 배지로만 구분한다.

| 뜻 | 색 | 쓰이는 곳 |
| --- | --- | --- |
| 확정 | 초록 | 확정 동선, 타임라인, "예" 버튼 |
| 확인 대기·재확인 필요 | 주황 | 대기 장면, 점선 경로, 우회 의심 구간 |
| 제외·번복 | 회색 + 취소선 | "아니오"로 뺀 후보, 번복된 기록 |
| 위험·실패·실시간 알림 | 빨강 | 위험 지역, 분석 실패, 출현 알림 |
| 현재 위치 범위 3단계 | 보라 진하기 | 높음은 진하게, 낮음은 옅게 |

현재 위치 범위를 보라로 한 이유: 빨강·주황을 쓰면 위험 지역·확인 대기와 겹쳐 "위험 지역과 겹침" 경고가 묻힌다.

## 글꼴·크기·밀도

글꼴은 Pretendard. 시각·유사도처럼 숫자가 세로로 줄지어 나오는 곳은 `font-variant-numeric: tabular-nums`.

| 용도 | 크기 | 예 |
| --- | --- | --- |
| 화면 제목 | 20px | 동선 추적 |
| 패널 제목 | 16px | 확인 요청, 후보 대기열 |
| 본문·버튼 | 14px | Ant Design 기본값 |
| 보조 정보 | 12px | 카메라·시각 설명, 범례, 지도 카메라 라벨 |
| 강조 숫자 | 18~20px | 확인 영역의 유사도 |

- 12px보다 작은 글자 금지.
- 폼과 확인 영역은 기본 간격. 후보 대기열, 결정 기록, 이용 기록, 계정 목록은 Ant Design `size="small"`(한 줄 약 40px).
- 시각은 24시간제 `15:02`, 날짜가 필요하면 `10/19 15:02`.
- 유사도는 소수점 둘째 자리(`0.71`), 경과 시간은 "32분 경과".

## 지도 표현 규칙

색만으로 구분하지 않고 모양·선 종류로 한 번 더 구분한다.

| 요소 | 모양 | 색 | 나오는 화면 |
| --- | --- | --- | --- |
| 고정 CCTV | 원 + 라벨(C1) + 촬영 방향 부채꼴 | 파랑, 분석 전이면 회색 | 전체 |
| 사건 영상(사설 CCTV 등) | 네모 + 라벨 | 파랑 | 해당 사건 |
| 도보 경로 | 가는 점선 | 회색 | 카메라·지도 설정 |
| 우회 의심 구간 | 점선 + 경고 라벨 | 주황 | 카메라·지도 설정 |
| 위험 지역 | 점선 테두리 + 옅은 채움 | 빨강 | 전체 |
| 확정 동선 | 굵은 실선 + 순번 원(1, 2, 3) | 초록 | 동선 추적, 현재 위치 |
| 확인 대기 구간 | 굵은 점선 + "?" 원 | 주황 | 동선 추적 |
| 지금 확인 중인 후보 | 카메라 마커에 링 | 파랑 | 동선 추적 |
| 현재 위치 범위 | 길을 따라 퍼진 채운 영역, 3단계 | 보라 진하기 | 현재 위치 수색 |
| 실시간 출현 위치 | 원 + 퍼지는 링 | 빨강 | 현재 위치 수색·실시간 감시 |

- 범례는 지도 왼쪽 아래에 항상, 그 화면에 나오는 요소만.
- 레이어 켜고 끄기 버튼은 지도 왼쪽 위. 위험 지역은 기본으로 켜 둔다.
- 바탕은 카카오맵 일반 지도 + 위성 지도 전환 버튼. 카카오맵은 바탕 지도 색을 바꿀 수 없다.
- 현재 위치 범위는 동심원이 아니라 길을 따라 퍼진 모양(SYS02-006). 길이 없는 하천 쪽으로는 뻗지 않는다.

| --- | --- | --- |

| 후보 카드 | 썸네일, 카메라·시각, 오른쪽 끝 유사도, 근거(✓ 경로 맞음, ↓ 이동 시간 부족, 필터 밖). 근거는 아이콘 + 글자 | 후보 대기열 |
| 확인 영역 | 기준 사진, 하이라이트 영상, 근거 3줄, 예/아니오/보류 버튼, 단축키 안내. 공동 담당자가 먼저 응답하면 "김OO님이 확정함"으로 바뀌고 버튼이 사라짐 | 동선 추적 |
| 장면 썸네일 | 테두리 색으로 상태(확정 초록 실선, 대기 주황 점선), 아래 카메라·시각. 누르면 영상 구간 재생 | 타임라인 |
| 되돌리기 알림 | 화면 아래 가운데 8초. 한 번에 하나, 새 판단이 앞 알림을 대신함 | 동선 추적 |
| 결정 기록 줄 | 시각, 담당자, 장면, 판단, 번복 버튼. 번복된 줄은 회색 취소선, 바로 아래에 번복 줄 | 동선 추적 |
| 실시간 출현 알림 | 오른쪽 패널 맨 위 빨간 테두리 카드. 다른 화면에서는 사이드바 숫자 배지 + 알림음 + 브라우저 알림 | 수색 화면 전체 |
| 사건 카드 | 사건 번호, 실종자, 실종 시각, 보행 속도, 경과 시간 | 사이드바 |
| 빈 화면 안내 | 할 일 한 문장 + 버튼 하나. 예: "기준 사진을 올리면 후보 검색을 시작해요" + [사진 올리기] | 전체 |
| 영상 재생기 | 해당 시각 앞뒤 10초 재생, 인물 박스. 동선 추적에서는 확인 영역 자리, 다른 화면에서는 팝업 | 전체 |

## 동선 추적 화면

후보 검색, 장면 확인, 경로 확인을 한 화면에서 한다. "예"를 누를 때마다 경로가 늘고 그 경로를 기준으로 다시 검색하므로 화면을 오가지 않게 모았다.

배치(위에서 아래로):

1. **질의 바**: 기준 사진, 시간 범위, 유사도 기준을 칩으로 항상 표시. 유사도 기준은 관리자 기본값(SYS01-006)으로 채워지고 사건마다 바꿀 수 있다. 조건을 바꾸면 그 자리에서 다시 검색.
2. **가운데 큰 영역 + 오른쪽 패널**: 위에 "검토 / 지도" 전환.
   - 검토(기본): 가운데 확인 영역, 오른쪽 미니맵 + 후보 대기열.
   - 지도: 가운데 큰 지도, 오른쪽 작아진 확인 영역. 남은 확인 개수가 계속 보인다.
3. **아래 탭**: 타임라인(확정 동선) | 결정 기록.

확인 영역:

- 장면은 한 번에 하나. 기준 사진은 항상 왼쪽, 후보 하이라이트(3~5초 자동 반복, 인물 박스)는 오른쪽.
- 예 / 아니오 / 보류 버튼 + 단축키 Y / N. 보류는 후보를 대기열 맨 뒤로 보내고 다음 후보로 넘어간다. 동선에는 영향 없음.
- 처음 들어오면 질의가 비어 있으므로 "기준 사진을 올리고 유사도 기준을 정하세요" 안내.

후보 대기열과 미니맵:

- 대기열은 유사도 순. 기준값 자리에 점선. 기준 미만은 접되 개수는 표시.
- 미니맵은 마지막 확정 지점과 지금 후보 카메라를 함께 표시.
- 검색 범위는 자동 필터(도보 이동 가능 카메라·시간대)만 쓴다. 지도에 직접 그리는 범위 선택은 넣지 않는다.

기록과 번복:

- 모든 판단(예 / 아니오 / 보류)은 결정 기록에 남는다.
- 판단 직후 8초 동안 되돌리기 알림. 8초가 지나도 결정 기록 탭에서 언제든 번복 가능.
- 번복해도 기록은 지우지 않는다. 원래 줄은 취소선, 번복 줄을 새로 추가.
- "예" 번복 → 그 뒤 확정 장면이 '재확인 필요'(SYS02-010). "아니오" 번복 → 후보가 대기열로 돌아온다.

## 나머지 화면

| 화면 | 틀 | 배치 |
| --- | --- | --- |
| 로그인 | 사이드바 없음 | 가운데 카드(시스템 이름, 아이디, 비밀번호, 로그인). 회원가입 대신 "계정은 관리자에게 요청하세요". 첫 로그인이면 같은 카드가 비밀번호 변경 폼으로 바뀜. 자동 로그아웃 뒤에는 안내 문구 |
| 사건 목록·등록 | 표형 | 진행 중 / 종료 탭 + 검색. 표: 사건 번호, 실종자, 실종 시각, 경과 시간, 확정·대기 수, 담당자. 확인 대기가 있으면 주황 배지. "사건 등록"은 오른쪽 폼(Drawer: 마지막 장소는 작은 지도에서 찍기, 보행 속도, 공동 담당자), 저장하면 동선 추적으로 이동. 사건 영상 추가·담당자 변경·사건 종료는 사건 안 헤더의 "사건 관리" 메뉴(사용자도 가능) |
| 영상 등록·분석 현황 (관리자) | 지도+표 | 위에 대기·진행·완료·실패 개수 카드. 왼쪽 카메라 지도: 마커에 영상 수, 실패는 빨간 링, 분석 중·대기는 파란 링, 영상 없음은 회색. 카메라를 누르면 표가 그 카메라 영상으로 걸러지고 "이 카메라에 영상 등록". 오른쪽 표: 파일, 카메라, 녹화 시작, 길이, 상태·진행률. 실패는 맨 위 + 재처리 버튼. "영상 등록"은 오른쪽 폼(카메라 + 작은 지도로 위치·방향 확인, 파일, 녹화 시작 시각). 카메라·지도 설정의 선택한 카메라 패널에도 그 카메라 영상 목록 |
| 설정 / 계정 / 이용 기록 (관리자) | 표형, 탭 4개 | 시스템 설정: 보행 속도·검색 기준·현재 위치 범위로 묶은 폼. 계정: 표 + 계정 추가, 줄마다 역할 변경·비활성화·비밀번호 초기화, 임시 비밀번호는 팝업으로 한 번만. 이용 기록: 기간·사용자·사건·행동 필터 + 읽기 전용 표. 데이터 보관: 보관 기간 설정 + 삭제 예정 목록 |
| 현재 위치 수색·실시간 감시 | 지도형 | 지도: 보라 3단계 범위, 위험 지역, 우선 수색 구역 번호. 오른쪽 패널(위부터): 실시간 출현 알림(있을 때만), 마지막 목격 장면과 경과 시간, 위험 지역 겹침 경고, 우선 수색 구역 목록, 실시간 감시 시작·중지와 상태. 사이드바 메뉴는 하나로 합치고 알림 숫자 배지 |

## 지원 환경

- 1920×1080 데스크톱 기준, 최소 너비 1280px(1366×768 노트북에서도 지도 700px 이상).
- 1280px보다 좁으면 사이드바를 아이콘만 보이게 접고, 그 이하는 가로 스크롤.
- 태블릿·휴대폰은 지원하지 않는다.
- 크롬 기준, 밝은 화면만(다크 모드 없음).

## 시안에서 바뀌는 점

- 강조색: 사용자 화면의 초록 버튼·메뉴 → 파랑. 초록은 확정 표시에만.
- 현재 위치 범위: 빨강·주황·노랑 동심원 → 길을 따라 퍼진 보라 3단계.
- 동선 추적: 오른쪽 작은 확인 카드 → 가운데 큰 확인 영역 + 검토/지도 전환, 질의 바와 결정 기록 탭 추가.
- 사이드바: "현재 위치 수색"과 "실시간 감시" → 메뉴 하나로 합침.
